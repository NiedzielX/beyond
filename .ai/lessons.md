# Shared project lessons

Read after the canonical ML state files and before implementation. Add or update evidence-backed lessons after meaningful fixes, rejected hypotheses and operational discoveries.

- [Prospective evidence, targets and cloud boundaries](lessons/2026-11-03-prospective-and-mae-evidence.md): distinct targets and denominators, frozen/exposed evidence, deployment proof, private recovery, hosted build evidence.
- [Capacity weighting rejected](lessons/2026-11-03-seat-weighting-rejected.md): mathematically aligned training loss can generalize worse; preserve the rejection, Pre-Live v3 anchor and earlier context results.
- [Context variance and lineage](lessons/2026-11-03-context-variance-and-lineage.md): large record counts can still contain no usable signal; preserve grouped variance, source identity and actual ingestion-time limitations.
- [Output shape is not accuracy](lessons/2026-11-04-output-shape-is-not-accuracy.md): actual near-flat prefixes can produce steep frozen forecasts; compare future errors honestly and preserve the issued baseline and difficult cases.
- [Feature capability is not learned signal](lessons/2026-11-04-feature-capability-is-not-learned-signal.md): all relative-value history coefficients in daily v1 are zero; exact decomposition explains the decline without proving error or authorizing a frozen-model repair.

- [Cloud proxy and exited workers](lessons/2026-11-04-cloud-proxy-and-exited-workers.md): preserve the working cloud environment; zombies answer kill(0), so require actual process state and a verified cycle after launch.

- [Live scoreboard scope](lessons/2026-11-04-live-scoreboard-scope.md): the newer encoder/P9summary excludes existing C1scores and panel forecasts; query actual model/package IDs before answering live-MAE questions.

- [Same-time C1/D2 audit](lessons/2026-11-04-c1-same-time-and-training-support.md): identical events do not imply identical forecast opportunities; numerical parity and missing history are distinct findings.

This index is durable memory, not a substitute for the authoritative execution plan or current handoff. No secrets or private source exports belong here.

- [Public data known-at and non-ready inputs](lessons/2026-11-04-public-source-known-at-and-nonready-input.md): verification time controls knowledge, larger score cohorts are not model improvements, and local DB repair does not prove hosted workflow redundancy.

- [Immutable knowledge-time input archives](lessons/2026-11-04-immutable-knowledge-time-inputs.md): row revisions need availability timestamps, API exact-count receipts prevent silent truncation, and actual pre-cutoff snapshots preserve prior source values without fabricating history.

- [Training expansion and retry proof](lessons/2026-11-05-training-expansion-and-retry-proof.md): support26 keeps old events exposed, exact input/model replay detects substituted forecasts, and an idempotent hosted retry does not create fresh DB evidence.

- [Fold preprocessing and dashboard clocks](lessons/2026-11-05-fold-preprocessing-and-dashboard-time.md): training-only fold representation and actual label availability; exposed sparse-context policy gains; fresh projections can retain elapsed unresolved candidates.

- [Residual runtime recovery and history support](lessons/2026-11-05-residual-runtime-and-history-support.md): cross-process pickle binding, byte-identical no-refit recovery, source presence versus consumption, exact value/missingness coefficient names, and fresh positive P9 chain scope.

- [Cron execution and prior clocks](lessons/2026-11-05-cron-execution-and-prior-clocks.md): scheduled YAML versus actual runs, broad due-set guards, durable dispatch accounting and later availability versus canonical cutoff.
