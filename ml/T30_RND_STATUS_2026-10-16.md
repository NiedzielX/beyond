No challenger is trained by this audit. 2024/25 and 2025/26 are not read.

## R&D decision rule from here

Do **not** create another challenger merely because one feature correlates with error in one season.

A v7 family is justified only if the mechanism audit finds a coherent repeated pattern across both rolling folds that:

- is point-in-time computable live;
- is not already adequately represented in the current feature contract;
- has a plausible demand mechanism;
- can be tested as a pre-registered structural change rather than parameter search.

If no such mechanism appears, pause historical T-30 tinkering and rely on prospective 2026/27 evidence before reopening model architecture.

## Non-negotiable rule

Do not describe 2024/25 + 2025/26 as untouched holdouts for **new T-30 R&D** after 2026-10-16. Historical benchmark documents may retain that wording as a statement about the protocol that existed when those frozen runtime results were originally produced.
