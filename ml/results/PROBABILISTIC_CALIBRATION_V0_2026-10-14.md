# Beyond Probabilistic Calibration v0 — 2026-10-14

Status: **research calibration candidate**  
Production impact: **none**  
Point model: **Global Model v2.1**

## Goal

Replace arbitrary forecast intervals around P50 with a leakage-safe, empirically calibrated P10–P90 interval whose real out-of-sample coverage can be measured.

## Method

For each forecast horizon independently:

1. Use the Global Model v2.1 model family selected on 2023/24 development data.
2. Build an out-of-sample residual distribution using only seasons available before the target holdout.
3. Estimate the signed residual 10th and 90th percentiles.
4. Set:
   - `P10 = max(0, P50 + residual_q10)`;
   - `P90 = max(P10, P50 + residual_q90)`.
5. For the next season, update calibration using only residuals from earlier completed seasons.

This is an empirical residual-quantile calibration layer. It is **not** yet a conditional quantile model and should not be presented as one.

## Leakage rule

For 2024/25 calibration, residual quantiles come from 2023/24 predictions generated by a model trained on 2021/22–2022/23.

For 2025/26 calibration, residual quantiles use prior out-of-sample residuals from 2023/24 and 2024/25 only. No 2025/26 outcome is used to calibrate its own interval.

### T-7 detail

Calibration from 2023/24 residuals for 2024/25:

- residual q10: approximately **-3,750**;
- residual q90: approximately **+3,304**;
- 2024/25 coverage: **87.3%**;
- lower-tail misses: **6.2%**;
- upper-tail misses: **6.5%**.

Updated calibration for 2025/26 using earlier OOS residuals:

- residual q10: approximately **-2,962**;
- residual q90: approximately **+2,839**;
- 2025/26 coverage: **82.0%**;
- lower-tail misses: **6.5%**;
- upper-tail misses: **11.4%**.

## Interpretation

The simple empirical calibration layer is already materially better than an arbitrary fixed percentage band:

- coverage is measurable;
- the nominal 80% interval is slightly conservative on 2024/25;
- coverage is close to target on 2025/26 (~81–84% across horizons);
- interval widths contract as kickoff approaches;
- 2025/26 shows an asymmetric upper-tail miss rate, indicating remaining underprediction risk in high-demand outcomes.

This asymmetry is useful model evidence rather than a reason to hide the interval. It tells us where the next probabilistic challenger should improve.

## Decision

**Keep empirical residual calibration v0 as the probabilistic baseline/champion for research.**

Do not yet call it the final probabilistic model.

Next challengers should include:

1. conditional quantile HistGradientBoosting / LightGBM / XGBoost where supported;
2. conformalized quantile regression or split-conformal residual calibration;
3. horizon-conditional and club-demand-level calibration;
4. explicit checks of pinball loss, empirical coverage and interval width;
5. calibration monitoring on genuinely future 2026/27 fixtures.

A probabilistic challenger should replace v0 only if it improves calibration and/or interval sharpness without degrading P50 quality.
