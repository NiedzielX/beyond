# Beyond Ticketing — Persistent Club Calibration v1

Last updated: **2026-10-18**

Status: **ACTIVE EXPERIMENT / a2 / NO PRODUCTION CHANGE**

## Purpose

Test one materially different a2 hypothesis after the unresolved-horizon multi-fold tournament:

> **Do clubs show persistent cross-season forecast residual bias that can safely calibrate the next season's Pre-Live forecast?**

This is deliberately separate from b2 current-season regime modeling.

## Boundary versus b2

For a target season, this calibration may use residuals from **strictly earlier completed seasons only**.

It may not use:

- any residual from the target season;
- live sales data;
- future match outcomes;
- current-season rolling residual state.

Therefore:

- a2 asks whether a club has persistent cross-season model bias;
- b2 later asks whether the current season is running above/below expected demand.

## Base model per horizon

Historical candidate state before this experiment:

- T-30: current incumbent;
- T-14: current incumbent;
- T-7: frozen historical candidate `hist31-leaf20-l2-1`;
- T-3: current incumbent;
- T-1: current incumbent.

Calibration is applied to that base; it does not reset T-7 to the production incumbent.

## PIT-safe residual archive

For each horizon, residual history is generated rolling out-of-season:

- train 2021/22 -> predict 2022/23;
- train through 2022/23 -> predict 2023/24;
- train through 2023/24 -> predict 2024/25;
- train through 2024/25 -> predict 2025/26.

Residual:

`residual_fraction = (actual_attendance - base_prediction) / verified_capacity`

The residual archive is therefore generated by a model that did not train on the scored season.

For calibration of target season S, only archive rows from seasons `< S` are visible.

## Fixed empirical-Bayes calibration

There is **no shrinkage hyperparameter grid** selected from reference holdouts.

### Robust input

Historical residual fractions are clipped to:

`[-0.25, +0.25]`

This prevents one extreme event from dominating variance estimation.

### Variance-based shrinkage

Per horizon and target season:

1. estimate pooled within-club residual variance;
2. estimate between-club mean-residual variance after removing expected sampling noise;
3. for each club with prior residual history, calculate reliability:

`w = between_variance / (between_variance + within_variance / n)`

4. shrink the club mean residual toward zero:

`posterior_club_residual = w * club_mean_residual`

### Safety cap

Final correction is capped at:

`+/- 5% verified capacity`

Final forecast:

`calibrated = clip(base_prediction + correction_fraction * capacity, 0, capacity)`

A club with no prior residual state receives zero correction.

## Why shrink toward zero

The hypothesis is persistent **club-specific model miss**, not a generic league or current-season regime correction.

Zero is therefore the prior expectation: if evidence is weak, trust the base model.

## Evaluation

Earliest identifiable target season:

- 2023/24 — development evidence, using 2022/23 OOS residual history.

Exposed references:

- 2024/25;
- 2025/26.

The fixed formula is frozen before reference scoring.

References do not tune:

- residual clip;
- variance estimator;
- shrinkage;
- correction cap;
- base model.

`promotion_allowed = false`

## Decision rules

Per horizon:

- if development MAE does not improve: `REJECTED_ON_DEVELOPMENT_REFERENCES_CANNOT_RESCUE`;
- if development improves and both references improve: `POSITIVE_DEVELOPMENT_AND_BOTH_REFERENCES`;
- if development improves and reference mean is positive but seasons disagree: `POSITIVE_DEVELOPMENT_POSITIVE_MEAN_MIXED_REFERENCES`;
- otherwise: `POSITIVE_DEVELOPMENT_NOT_PROVEN_ON_REFERENCES`.

A positive historical result can create a frozen historical Pre-Live candidate layer, not an automatic production change.

## Required evidence

Persist per horizon/season:

- base MAE;
- calibrated MAE;
- MAE improvement;
- median AE;
- p90 AE;
- bias;
- WAPE;
- event improvement rate;
- worst event degradation + identity;
- club breakdown;
- correction coverage;
- number of prior residual rows/clubs;
- within/between variance;
- reliability per club;
- correction fraction per club;
- exact residual source seasons.
